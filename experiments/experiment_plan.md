# DynaGS 小论文实验计划

> 状态（2026-10-30）：实验一（Oracle 20-QTL）和实验二（未知QTL+训练集筛选）均已完成 `300/300` 个正式运行并通过产物完整性审计。实验三协议已冻结，尚未开始编写比较模型或启动比较训练；实验四、五尚未开始。
>
> 总原则：先冻结数据、划分、指标、比较方法和图表规范，再实现统一实验入口；测试集只用于一次最终评估，模拟真值不得进入训练、筛选或调参。

## 1. 研究问题与论文主张

论文围绕五个问题组织，而不是围绕若干零散训练任务组织。

1. **Oracle-QTL 场景**：从完整模拟数据中直接取出 20 个真实 QTL 作为输入时，DynaGS 能否准确恢复个体动态曲线，并定位主要拐点？
2. **未知 QTL 筛选场景**：使用同一份完整模拟数据、但不向模型提供 QTL 真值时，训练集内筛选能否保留因果信号，并接近 Oracle-QTL 的预测上界？
3. **模拟数据模型比较**：在未知QTL、高维输入的端到端场景中，DynaGS 相比经典基因组选择、机器学习和深度学习方法是否有稳定优势？
4. **真实数据模型比较**：这种优势能否在后续确定的独立真实动态表型数据上复现？
5. **消融实验**：训练集内条件残差筛选、Wide、Deep 和门控融合分别贡献了什么；筛选后的位点是否足以让简单预测器恢复主要信号？

建议论文只作以下可由实验直接支持的主张：

- DynaGS 提升未见个体的动态表型预测，而不是声称识别了真实生物机制。
- 模拟数据中的 QTL 恢复能力只适用于本文预设的遗传结构、LD、遗传率和样本量。
- 真实数据没有 QTL 真值，因此只报告预测能力、稳定性和效率，不报告“因果位点识别率”。

## 2. 统一实验原则

### 2.1 数据隔离

- 每个模拟重复先生成完整数据，再按个体划分为 train/validation/test = 0.8/0.1/0.1；固定划分种子为 73。
- 同一个模拟重复内，所有模型复用完全相同的个体划分。不同模拟重复使用不同的数据生成种子。
- 缺失填补、表型标准化、PCA、GWAS、DC-SIS、特征标准化和任何超参数选择只能拟合 train。
- validation 只用于早停和选参；test 在模型与阈值冻结后只评估一次。
- 模拟数据的 `true_gv`、因果位点、真实效应和潜在无噪声曲线只用于测试后诊断，禁止作为模型输入或选参依据。
- 真实数据使用外层交叉验证；每个外层测试折必须在其余个体上重新执行完整预处理和筛选。

### 2.2 随机性与重复

- 全局基准种子为 73；后续种子由明确公式生成并写入清单，不使用运行时间生成种子。
- 所有正式模拟条件统一使用 **10 个独立数据重复**。重复是统计推断的实验单位，不能把同一重复中的个体或时间点当作独立重复。
- 每个数据重复中，神经网络使用一个预注册初始化种子。主分析不额外增加初始化重复；如计算预算允许，可在补充材料中选择 3 个预注册代表重复，各运行 3 个初始化种子检查训练随机性。
- 真实数据使用 **5 折外层交叉验证 × 5 个重复划分**。如果存在家系、群体或环境分组信息，主分析改为按组划分；普通随机划分降为敏感性分析。

### 2.3 公平比较

- 所有模型使用相同的 train/validation/test 个体、相同的原始表型和同一套反归一化后的测试指标。
- 训练预算、早停上限和超参数搜索空间在运行前写入配置；不能只为某个模型追加搜索。
- 模型选择依据 validation 的预注册主指标，不能依据 test 或模拟 QTL 真值。
- 实验三仅进行**端到端系统比较**：DynaGS 使用其训练集内条件残差筛选流程；其他模型使用完整10,000个SNP。该比较回答“在未知QTL时，实际使用哪个完整系统更好”。它不能单独归因于DynaGS的网络结构；筛选与结构的贡献由实验五消融拆分。

## 3. 数据与实验场景

### 3.1 模拟数据共同设置与条件设计

采用平衡的 `2 × 5 × 3` 全因子设计，QTL 数始终固定为 20：

| 因素 | 水平数 | 水平 |
| --- | ---: | --- |
| 总位点数 P | 2 | 5,000、10,000 |
| 实际训练样本量 NTR | 5 | 100、200、400、800、1,600 |
| 遗传力 h² | 3 | 0.1、0.4、0.8 |

共有 `2 × 5 × 3 = 30` 个参数条件，每个条件生成 10 个独立重复。每份数据都成对运行实验一和实验二，因此主实验共计 `30 × 10 × 2 = 600` 次 DynaGS 训练，不含失败重跑、基线和消融。条件 ID 统一使用 `P{P}_NTR{NTR}_H{h²}`，例如 `P10000_NTR400_H0.4`。

每个条件和重复均作为独立模拟数据集生成；同一条件内的 `rep_01`–`rep_10` 使用固定模拟种子73–82。20个QTL固定从前5,000个候选位点中选择，`P=10,000` 条件仍保证QTL位于此前5,000位点池中。Oracle与Screened对同一条件、同一重复严格复用同一数据和个体划分；不同P、NTR或h²条件之间不假设嵌套个体或嵌套位点关系。

其他共同参数为：时间坐标固定为 `1, 2, ..., 20`、LD 参数 0.3、QTL 类型比例 additive 0.4 / dominance 0.3 / mixed 0.3、dominance ratio 0.3、`n_epistasis=0`、残差 AR(1) 相关 0.6，个体划分比例 0.8/0.1/0.1。

本方案中的NTR明确定义为**实际训练集样本量**。为复用现有“读取完整数据后按8:1:1划分”的流程，NTR为100、200、400、800、1,600时，分别生成总样本124、250、500、1,000、2,000；现有取整规则对应的train/validation/test数量分别为100/12/12、200/25/25、400/50/50、800/100/100和1,600/200/200。论文图表横轴写作 `Training sample size (NTR)`，并同时报告生成总数和三组实际数量。

正式模拟数据已在 `truth/true_curve.csv` 导出潜在无噪声表型 `Y_true`，以便将“拟合观测噪声”和“恢复真实曲线”分开。该文件仅用于测试后诊断、曲线重合度与拐点误差计算，必须标注为 evaluation-only，且不得进入训练、筛选或调参。

### 3.2 模拟数据文件接口

模拟数据不再强制使用 `genotype.npy` 和 `cleaned_pheno/sim_pheno.csv`，统一改为扁平目录：

```text
<condition_rep>/
├── sim_snp.npy                 # 推荐的正式训练格式
│   或 sim_snp.csv             # 可直接训练的原始CSV格式，二选一
├── sim_pheno.csv
├── sample_ids.csv
├── simulation_config.json
├── data_manifest.json
├── splits/
└── truth/
```

SNP加载器按文件后缀接收 `.npy` 或 `.csv`。`sim_snp.npy` 必须是二维0/1/2剂量矩阵，并通过 `sample_ids.csv` 提供行身份；`sim_snp.csv` 的第一列必须为 `SampleID`，其余列为0/1/2剂量。模拟用 `sim_pheno.csv` 的第一列同样为 `SampleID`，其余列为时间点；加载时必须验证SNP、表型和 `sample_ids.csv` 的ID及顺序完全一致，再去除ID列进入模型。真实数据原有的无ID表型格式继续兼容，但不得自动猜测身份。

原“CSV转NPY”步骤改为可选的性能优化，不再是训练前必经步骤。直接读取CSV时仍必须执行数值编码、有限值、维度、SampleID、时间列、split和manifest校验；不得因省略格式转换而省略这些数据契约。`.npy` 支持mmap且重复训练读取更快，因此正式大规模实验仍推荐优先生成或缓存 `sim_snp.npy`；CSV直接输入主要用于让模拟器产物无需人工转换即可运行。

每个正式数据目录必须保存 `generation_request.json`、`simulation_config.json`。生成、曲线、发布和调度脚本按内容哈希保存到共享的 `dataset/experiments/provenance/generator_<hash>/`；每个数据manifest记录版本包路径及SHA-256。后续仓库脚本更新不得改写既有版本包。

### 3.3 实验一 S1：同一完整数据的 Oracle-QTL 输入

- 从每份完整模拟数据中按真值索引取出固定的 20 个 QTL，不重新生成一份只有 20 位点的数据。
- 不进行特征筛选。该实验是模型表达能力和可达到性能的理想上界，不是现实可部署方法。
- 目的：检验曲线恢复与拐点定位，并为实验二量化筛选带来的性能差距。
- 主要结果：潜在曲线误差、观测表型预测、拐点误差，以及 `Oracle - Screened` 的重复内配对差值。

### 3.4 实验二 S2：同一完整数据的未知 QTL 筛选输入

- 输入对应条件下的全部 `P` 个位点，不向模型、筛选器或调参过程提供真实 QTL 索引。
- 已完成的正式主流程仅使用训练个体：第一轮多元GWAS和DC-SIS各保留100个候选；依据最强15个候选回归其加性和显性效应后，对残差重复筛选；候选集合经固定多任务Elastic Net压缩为最终20个SNP。
- 每个正式重复的最终输入维数均为20，`screen_k=100`、`gwas_k=100`、`screen_condition_k=15`，且真QTL文件不进入模型、筛选或调参过程。
- GWAS-only、DC-SIS-only、随机筛选、不同最终K和候选并集属于后续筛选消融（E5/补充材料），不追溯改写已经完成的600次主运行。

### 3.5 真实数据 R1（最后开展，数据集待定）

- 真实实验不使用当前仓库中的玉米数据；具体数据源、表型、时间坐标和SNP范围尚未冻结。
- 在模拟实验、模型比较和消融完成后，再对候选真实数据执行只读预检并单独形成真实数据实验补充方案。
- 训练前必须冻结样本身份、表型清单、时间坐标、群体/家系/环境信息、缺失率、MAF、文件 SHA-256、样本 ID 哈希和划分策略。
- 真实数据没有QTL和潜在曲线真值，只报告预测、稳定性和效率，不沿用模拟数据的QTL恢复结论。

## 4. 比较模型

实验三采用经过输入条件、许可证和代码可行性审查后的代表性模型。外部深度模型均只接受SNP输入，不使用测试个体早期表型、环境协变量、转录组、SNP—基因网络或外部QTL先验。

| 类别 | 模型 | 角色 |
| --- | --- | --- |
| 无基因型基线 | Mean | 各时间点训练集均值，最低基线 |
| 传统统计 | Ridge-All、Ridge-A+D、GBLUP-All、RR-GBLUP | 加性、显性、核和动态随机回归基线 |
| 树模型 | Random Forest | 非线性机器学习基线 |
| Boosting | XGBoost | 强通用表格基线 |
| 深度学习 | DNNGP-SNP、DLGWAS、WheatGP、Cropformer | 逐时间点SNP预测的CNN、双流CNN、CNN+LSTM、CNN+注意力基线 |
| 本文模型 | DynaGS | 联合20时间点的Wide–Deep门控模型 |

### 4.1 实验三模型选择依据与排除边界

- **Mean** 给出不使用基因型时的最低可接受预测水平；若复杂模型不能稳定超过它，则不应讨论方法优势。
- **Ridge-All、Ridge-A+D、GBLUP-All、RR-GBLUP** 覆盖基因组选择中最常用的线性加性、加性+显性、核方法和动态随机回归范式，用于判断收益是否超过传统统计建模。
- **Random Forest、XGBoost** 覆盖非神经网络的树集成学习，检验DynaGS的优势是否只是来自一般的非线性拟合能力。
- **DNNGP-SNP、DLGWAS、WheatGP、Cropformer** 分别代表SNP一维卷积、双流表征、CNN+时序循环和CNN+注意力的已发表深度学习思路；它们与DynaGS的数据类型相容，但原始任务为单时间点预测，故按统一协议逐时间点独立训练。
- **DynaGS** 是唯一直接联合预测20个时间点的模型；实验三检验完整系统的实际表现，不将其结果表述为“仅由联合动态架构带来的提升”。筛选、Wide、Deep和gate的独立贡献由E5检验。
- 不纳入需要环境、组学、SNP—基因网络、早期表型或外部QTL先验的方法；也不纳入无法在相同个体划分、完整10,000 SNP输入和公开/可独立实现条件下公平运行的方法。此前候选的 dynamicGP、NetGP-SNP、PKDP不属于最终E3模型名单。

RR-GBLUP、四个深度学习适配器及实验三统一调度器尚待实现。DNNGP-SNP与DLGWAS将依据原论文结构独立适配实现，不复制或修改未明确授权的官方代码；WheatGP和Cropformer使用其明确许可允许的核心结构适配。所有适配改变、参数量和输入编码均记录在run manifest中。

外部单时间点模型在每个重复内对20个时间点分别训练20个独立预测器，再拼接为完整轨迹；DynaGS一次联合预测全部20个时间点。所有模型共享同一个体级train/validation/test划分、完整10,000 SNP输入和反归一化测试指标。Oracle仅保留为实验一的DynaGS上界诊断，不进入实验三模型排名。

## 5. 评价指标

### 5.1 指标层级

每项实验只设少量主指标，其余作为解释性指标，避免“指标越多越容易挑出显著结果”。所有误差指标在**反归一化后的原始表型尺度**计算。

**预测性能主指标**：

1. **PCC**：每个时间点跨个体计算 Pearson 相关，再对有效时间点取平均；反映育种排序能力。
2. **NRMSE**：`RMSE / (训练集表型 P95 - P5)`；用于跨表型、跨场景比较。分母只由 train 决定。
3. **Time-adjusted R²**：沿用仓库现有协议，以各时间点均值为基线计算整体 R²；报告时明确它不是普通 flatten R²。

**次指标**：MAE、RMSE、Spearman 相关、每个时间点 PCC/NRMSE、运行时间、峰值显存/内存、参数量和最终输入位点数。

不再把 MSE 与 RMSE 同时作为两个主结论，因为二者信息重复。

### 5.2 曲线重合度与形状恢复

“看起来重合”必须转化为数值。模拟数据以潜在无噪声曲线 `Y_true` 为主要参照，观测曲线 `Y` 的指标单独报告。

1. **个体曲线 NRMSE**：先对每个测试个体跨时间计算 RMSE，再用该重复训练集的 P95–P5 缩放，最后对个体取平均。
2. **曲线一致性相关系数（CCC）**：对每个个体的预测与真值时间序列计算 Lin's CCC，再汇总中位数和四分位距。CCC 同时惩罚形状、位置和尺度偏差。
3. **归一化积分绝对误差（nIAE）**：在共同稠密时间网格上计算 `∫|ŷ(t)-y(t)|dt / [(tmax-tmin) × train(P95-P5)]`。
4. **形状误差**：每条曲线先减去自身均值并除以自身标准差，再计算 RMSE；用于区分“整体偏高/偏低”和“动态形状错误”。常数曲线记为无效并报告有效率。

论文主文优先展示个体曲线 NRMSE 和 CCC；nIAE、形状误差放补充材料。DTW 不作为主指标，因为它允许时间轴扭曲，可能掩盖拐点时间预测错误。

### 5.3 拐点指标

本文把生长曲线的**主拐点**定义为一阶导数取得全局最大值的时间，即最大生长速率时刻。计算协议如下：

1. 对预测曲线和潜在真值使用相同的 PCHIP 插值到 1,000 个等距时间点；不对预测曲线单独使用更强平滑。
2. 在去除两端各 5% 的内部时间区间寻找最大一阶导数位置。
3. 若最大导数非正、最优点落在排除边界，或曲线有效变化幅度低于训练集尺度的 1%，则该个体记为“无有效主拐点”。
4. 报告：
   - 拐点时间 MAE（主指标，单位为原时间坐标）；
   - 拐点时间有符号偏差；
   - 落在一个原始采样间隔内的比例；
   - 最大生长速率相对误差；
   - 预测与真值均有效的个体比例。

若后续真实表型不是单调生长曲线，主文不强行称为 Logistic 拐点，而根据生物学含义改报**峰值时间**和**最大上升速率时间**。真实数据没有潜在稠密真值，相关分析只能标记为描述性结果。

### 5.4 SNP 筛选指标（仅模拟数据）

在每个重复中报告：

- `Recall@K = 被选中的真实 QTL 数 / 20`；
- `Precision@K = 被选中的真实 QTL 数 / K`；
- F1；
- 相对随机选择的富集倍数；
- 20 个 QTL 的排名分布、中位排名和最差排名；
- 不同重复/训练重采样间的 Jaccard 稳定性。

考虑 LD 后增加一个次指标：若入选 SNP 与某真实 QTL 在 train 中的剂量相关 `r² ≥ 0.8`，则记作该 QTL 的 tag hit。必须同时报告 exact recall 和 LD-aware recall，不能只选较好看的一个。经验 LD 只能用 train 估计。

### 5.5 计算效率

- 端到端 wall-clock 时间：包括筛选、预处理、训练和预测；
- 单独训练时间和单独筛选时间；
- 峰值 GPU 显存或 CPU RSS；
- 可训练参数量、输入位点数、最佳 epoch。

不同硬件的时间不能直接混合平均。所有效率结果记录 CPU、GPU、线程数、软件版本和是否命中缓存；论文正式计时禁用跨模型不公平缓存。

## 6. 五组实验的具体执行矩阵

### E1：DynaGS 在 S1 上的曲线恢复

- 30 个全因子参数条件各使用 10 个模拟重复。每个重复从完整数据中提取真实 20 QTL，训练完整 DynaGS，不筛选。
- 测试集同时对观测 `Y` 和潜在 `Y_true` 计算指标。
- 主结果：PCC、NRMSE、Time-adjusted R²、曲线 CCC、拐点时间 MAE。
- 图 E1a：测试集中按潜在真值曲线均值分层后固定抽取 6 个个体，画 truth、observation、prediction；个体选择规则预先固定，不能手挑最好曲线。
- 图 E1b：所有测试个体的拐点真值–预测散点图，带 identity line。
- 图 E1c：20 个时间点上的 PCC/NRMSE 均值和 95% CI。

### E2：DynaGS + 筛选在 S2 上的表现

- 与E1完全相同的30×10份数据，使用已完成的条件残差筛选主流程和最终20 SNP输入。
- 主结果：预测性能、exact recall、LD-aware recall、precision、筛选稳定性与端到端效率。
- 图E2a：全因子预测性能，与E1同一布局，比较Oracle与Screened的性能差距。

### E3：模拟数据模型比较

- 固定参考参数组合为 `P=10,000, NTR=400, h²=0.8, QTL=20`，复用已生成的同一10个独立重复；“一套固定数据”指一套固定参数设置，而不是单个随机数据文件。
- 仅执行端到端轨道：DynaGS使用自身训练集内筛选流程；Mean不使用SNP；其余所有模型使用完整10,000 SNP。不得向任何比较模型提供Oracle QTL或DynaGS筛选索引。
- 深度学习模型按20个时间点独立训练；每个时间点使用同一训练/验证/测试个体划分。模型选择和早停仅使用validation，20个单时间点预测再拼接为完整曲线。
- 每个模型的超参数搜索数量、最大epoch、早停规则和资源记录方式在运行前冻结到配置；test只在最终参数确定后评估一次。
- 主表：每模型的10重复均值、标准差、重复级bootstrap 95% CI，以及相对DynaGS的同一重复配对差值和CI。
- 主图：每个重复内相对Mean的性能增益，采用配对点线图或raincloud/box加原始点；不要只画无误差线的柱状图。
- 补充图：准确度–运行时间Pareto图、逐时间点性能热图，以及代表重复的曲线和拐点比较图。

### E4：真实数据模型比较（暂缓）

- 数据集确定后再冻结外层交叉验证、分组划分、表型和指标细节；在此之前不生成真实实验配置。
- 原则上每个外层折内部固定训练侧 validation 用于早停/选参，外层测试折完全隔离；如存在群体、家系或环境结构，应优先使用分组划分。
- 候选主指标为PCC、NRMSE和Time-adjusted R²，并报告逐时间点结果；最终以数据的实际表型含义为准。

### E5：消融实验

E5 是**机制拆解**，不改变 E3 的端到端主比较。E3 中除 DynaGS 外的模型仍固定使用完整 10,000 SNP；任何复用 DynaGS 筛选位点的结果均只能标为 `DynaGS-screened + <downstream model>`，不得改名为或并入 E3 的 Ridge-All、Random Forest、XGBoost 等独立基线。

E5 在 S2 的固定参考条件 `P=10,000, NTR=400, h²=0.8, QTL=20`、同一 10 个独立重复和原始个体划分上执行。筛选器在每个重复中只能用该重复的训练个体拟合；得到的 SNP 索引固定后才可变换该重复的 train、validation、test。真实 QTL、DynaGS 的 test 预测及 test 标签均不得进入筛选、选参或早停。

#### E5a：筛选与下游预测器的机制拆解

| 管线 | 输入 SNP | 回答的问题 |
| --- | --- | --- |
| 完整 DynaGS | DynaGS 训练集内筛选后的位点 | 端到端系统总效果 |
| DynaGS 无筛选 | 完整 10,000 SNP | 筛选对 DynaGS 本身是否必要 |
| `DynaGS-screened + Ridge` | 同一训练集筛选结果 | 筛选本身能否使简单线性预测器恢复信号 |
| `DynaGS-screened + Random Forest` | 同一训练集筛选结果 | 筛选与非线性树模型是否互补 |
| `DynaGS-screened + XGBoost` | 同一训练集筛选结果 | 筛选与 boosting 是否互补 |

- `DynaGS-screened + <model>` 的下游模型只可在筛选后的 SNP 上训练；其超参数和早停仍仅由 validation 决定，test 只作一次最终评估。
- 这组结果量化的是**共享训练侧预处理带来的收益**，不是对外部模型原始端到端能力的重新排名。
- 若筛选后 Ridge/树模型已与完整 DynaGS 持平或更好，论文应将条件残差筛选定位为主要贡献；若完整 DynaGS 仍稳定更好，才可主张筛选与后续架构存在额外协同。

#### E5b：DynaGS 结构消融

核心结构消融直接对应现有模式：

| 模式 | 含义 | 回答的问题 |
| --- | --- | --- |
| `all` | Wide + Deep + gate | 完整模型 |
| `wide` | 仅 Legendre Wide | 时间加性通路能解释多少 |
| `deep` | 仅 Transformer Deep | 非线性/交互通路能解释多少 |
| `add` | Wide + Deep 直接相加 | 自适应门控是否必要 |

- 核心消融先在 S1、S2 固定参考条件上运行；真实数据消融待真实数据方案冻结后再决定。
- 结构消融主比较为 `all` 对其余三种模式，不把大量超参数敏感性混进同一张图。
- 时间基函数阶数 `degree ∈ {0, 1, 3, 5, 7}` 作为单独敏感性实验。
- 筛选方法敏感性沿用 E2 的 GWAS-only、DC-SIS-only、串联、并集和 Random；它与 E5a 的“固定同一筛选结果、更换下游模型”是两个不同问题，须分表报告。
- 可选训练策略消融（损失函数、L1、归一化方式）只有在核心结论完成后进行，放补充材料。
- 消融模型使用相同初始化规则和相同选参预算；同时报告参数量，避免把容量差异误解释为组件贡献。
- E5 主分析同时报告完整 DynaGS 与各消融/共享筛选管线的重复内配对差值、10 个原始重复点、95% CI、最终输入 SNP 数、筛选耗时和训练耗时；不得仅展示最有利的下游预测器。

## 7. 统计分析

### 7.1 汇总与置信区间

- 模拟实验按 10 个独立数据重复汇总，报告 mean ± SD、median [IQR]、全部 10 个原始点和重复级 bootstrap 95% CI。由于重复数较少，置信区间可能较宽，结论以配对差值大小、方向一致性和区间为主。
- 30个条件不进行所有两两比较。全因子趋势使用重复编号作为配对/随机区组，分析NTR、P、h²的主效应及预注册的 `NTR×h²`、`NTR×P`、`P×h²` 交互；NTR在模型中使用 `log2(NTR)`，h²先按三水平分类变量处理。三阶交互只作探索性报告。
- 模型间报告同一重复内的配对差值，例如 `PCC_DynaGS - PCC_baseline`、`NRMSE_baseline - NRMSE_DynaGS`；正值统一表示 DynaGS 更优。
- 主显著性检验使用双侧精确配对置换检验：10 个重复的差值共有 `2^10 = 1,024` 种符号翻转，枚举全部情况；同时报告配对标准化效应量。小样本下不把 p 值作为唯一证据。
- 多模型与多主指标比较使用 Holm 校正。探索性全表型分析使用 Benjamini–Hochberg FDR。

### 7.2 真实数据注意事项

- 外层折共享训练个体，不能把 25 个折简单视为完全独立样本做普通 t 检验。
- 主推断以每个重复划分聚合后的配对差值为单位，并用按“重复划分”分组的 bootstrap 给 CI；同时报告所有外层折原始点作为透明展示。
- 若样本量允许，增加按测试个体重采样的 out-of-fold prediction bootstrap，作为预测差异的敏感性分析。
- 重点解释效应大小和 CI，不以 `p < 0.05` 代替实际意义。

### 7.3 缺失与无效值

- PCC 分母为零、拐点无效、曲线标准差为零时不得静默填 0；保存为 NA，并报告有效计数/总计数。
- 单次运行失败不得直接删除。记录失败原因；主分析要求每个模型在同一组重复上做 complete-case 配对，并另报失败率。
- 不允许仅对表现差的模型重跑。因工程故障重跑时保留原日志并使用同一 seed。

## 8. 期刊级绘图规范

### 8.1 全局样式

- 图内文字统一使用英文，图注可按投稿期刊要求使用英文或中文。
- 默认字体优先 Arial；环境缺失时统一回退 DejaVu Sans。发布 PDF 时嵌入字体，禁止同一图混用字体。
- 单栏宽 3.35 in，双栏宽 7.10 in；高度按内容控制，通常不超过 7.10 in。
- 最终排版字号：轴标题 8 pt，刻度/图例 7 pt，分面标签 9 pt bold。
- 主线宽 1.2 pt，辅助线 0.7 pt，散点 3–4 pt；identity line 使用浅灰虚线。
- 白色背景、向外刻度、去除上/右边框；网格只保留必要的浅灰主网格。
- 数值轴从科学意义合理范围开始；相关系数统一 `[-1, 1]` 或在图注中明确截取范围，误差指标不得人为截断异常值；连续数轴通常保留5–7个主刻度。R²图只要包含0或负值，必须显示R²=0的浅灰虚线。
- NTR主图横轴固定按 `100, 200, 400, 800, 1600` 递增显示，不因统计模型的`log2(NTR)`表示而改变坐标轴含义。分类标签默认不旋转，必要时30°右对齐，45°仅作最后手段。

### 8.2 颜色与映射

采用色盲友好配色，并在所有图中固定模型颜色、marker和线型。唯一全局样式源为 [dynags-figure skill](../.codex/skills/dynags-figure/SKILL.md) 及其 `scripts/plot_style.py`；图脚本不得自行创造模型配色。

| 对象 | 色值 |
| --- | --- |
| DynaGS | `#0072B2` |
| Mean | `#4D4D4D` |
| Ridge-All / Ridge-A+D | `#009E73` / `#44AA99` |
| GBLUP-All / RR-GBLUP | `#E69F00` / `#D55E00` |
| Random Forest / XGBoost | `#CC79A7` / `#882255` |
| DNNGP-SNP / DLGWAS | `#999933` / `#332288` |
| WheatGP / Cropformer | `#88CCEE` / `#AA4499` |
| Truth | `#000000` |
| Observation | `#B3B3B3` |

- 同一模型跨图颜色、marker和线型不变；DynaGS始终使用蓝色实线圆点。不同筛选方法使用线型和点形辅助编码，不能只靠颜色。
- 连续热图使用感知均匀的 `viridis`；以 0 为中心的差值使用对称发散色图。
- 误差带透明度约 0.18；大量个体曲线使用低透明度，叠加粗体均值线。

### 8.3 图形选择与导出

- 模型比较优先使用 paired dot、box/violin + raw points、forest plot；避免 3D 图、雷达图和只显示均值的柱状图。
- 曲线图必须显示原时间坐标、单位、truth/prediction/observation 的清晰图例；图例顺序全篇一致。
- 每张主图使用 `A, B, C...` 左上角分面标签，图内不放长标题，解释写入 caption。
- 多面板图默认使用 `layout="constrained"`；共享图例优先放于图外，使用无边框图例。单个panel图例仅限不遮挡数据时使用。手动留白时以 `left=0.10, right=0.98, bottom=0.16, top=0.93, wspace=0.30, hspace=0.35` 为起点。
- 主输出同时保存矢量 PDF/SVG、600 dpi TIFF和300 dpi PNG预览。
- 保存绘图所用 `figure_XX_data.csv`、`figure_XX_metadata.json`、绘图配置、软件版本和生成命令，使每张图可从汇总表独立重建。
- 禁止在 Illustrator 中手工移动数据点或修改数值；允许最终拼版，但必须保留原始程序输出。

### 8.4 结果数据、汇总表与绘图流水线

结果按四层保存，任何论文图都不得直接解析训练日志：

1. **单次运行原始层**：模型预测、目标、split、筛选索引、配置、运行状态和资源消耗；
2. **统一长表层**：把不同模型产物转换成相同字段的 tidy CSV；
3. **统计汇总层**：按条件和重复计算均值、离散度、置信区间及配对差值；
4. **论文图表层**：每张图只读取一个冻结的 `figure_XX_data.csv`，并同时输出图、`figure_XX_metadata.json`和caption所需数值。

建议生成以下总表：

| 文件 | 一行代表什么 | 关键字段 |
| --- | --- | --- |
| `run_index.csv` | 一次训练运行 | run_id、P、N、h²、rep、Oracle/Screened、model、seed、split_hash、status |
| `metrics_overall_long.csv` | 一次运行的一个整体指标 | run_id、target（observed/latent）、metric、value、valid_n |
| `metrics_by_time.csv` | 一次运行在一个时间点的指标 | run_id、time、metric、value、valid_n |
| `curve_metrics_individual.csv` | 一个测试个体的曲线指标 | run_id、SampleID、CCC、nRMSE、nIAE、inflection_error、valid |
| `screening_metrics.csv` | 一次筛选结果 | run_id、K、exact_recall、LD_recall、precision、F1、median_rank |

预测矩阵保留为压缩 NPZ，不将所有个体×时间点预测重复写入大型 CSV；只有绘图和统计所需的派生长表写 CSV。所有数值表保留未四舍五入值，论文表格展示时再统一保留3位小数或按量纲决定有效位数。

正式汇总前执行完整性门禁：主 DynaGS 网格预期为30条件×10重复×2模式=600个成功 run；每个条件必须恰好有10个不同 rep，Oracle 和 Screened 必须具有相同 dataset/split 哈希，不允许重复 run_id。缺失、失败或哈希不配对时停止正式出图，并单独生成 `run_failures.csv`；不得静默忽略失败运行。

## 11. 编码前必须冻结的决策与验收门槛

### 11.1 已锁定的决策

1. E1/E2固定 `P={5000,10000} × NTR={100,200,400,800,1600} × h²={0.1,0.4,0.8}` 的30个全因子条件，每条件10个重复，已完成600个DynaGS正式运行。
2. E3固定参考条件为 `P10000_NTR400_H0.8`；使用同一10个重复，仅进行端到端比较。
3. E3模型名单固定为 Mean、Ridge-All、Ridge-A+D、GBLUP-All、RR-GBLUP、Random Forest、XGBoost、DNNGP-SNP、DLGWAS、WheatGP、Cropformer和DynaGS。
4. E3外部深度模型使用完整10,000 SNP、逐时间点独立训练；DNNGP-SNP与DLGWAS采用独立适配实现，WheatGP/Cropformer记录上游许可证与适配变化。
5. 图内可见文字使用英文，且统一使用 `DynaGS` 和 `Random Forest`；字体、尺寸、图例、数轴、留白及PNG/SVG/PDF/TIFF/数据导出执行 `dynags-figure` skill。
6. 真实数据集、表型和划分策略留到模拟实验、模型比较与消融完成后另行冻结。

### 11.2 开始大规模实验前的工程验收

- 用一个 `N=100, P=200` 的 smoke 数据完成生成、准备、训练、基线、汇总、作图全链路。
- 人工构造简单曲线验证 nIAE、CCC 和拐点时间误差：完全相同曲线误差为 0，固定时间平移能得到已知误差。
- 人工构造已知 QTL 集验证 exact recall、LD-aware recall 和位点索引不存在 off-by-one。
- 验证 scaler、PCA 和筛选器从未读取 validation/test 标签。
- 同一配置和 seed 重跑得到一致 split、筛选索引和容差内一致指标。
- 确认所有模型测试集只评估一次，输出中包含协议版本。
- 先完成 3 个模拟重复的 pilot，只用于估计运行时间、内存和发现工程问题，不用于修改主假设或挑选结果；任何参数变更必须更新本文档版本后重新开始正式重复。

## 12. 建议实施顺序

1. 对已完成E1/E2的600个run生成冻结汇总表、曲线/拐点/筛选诊断指标，并使用dynags-figure输出E1/E2图形初稿。
2. 定义E3统一结果schema、配置schema、run manifest与固定调参预算。
3. 使用非正式smoke数据验证Mean、传统统计、机器学习、RR-GBLUP和四个深度学习适配器；不在10个正式重复上边开发边调参。
4. 完成E3代码审查后，运行10个正式重复的端到端模型比较。
5. 由冻结原始manifest一次性生成E3统计表、主图和补充图，禁止手工汇总。
6. 在E1/E2/E3结论冻结后执行E5消融；最后确定真实数据并进行E4。
